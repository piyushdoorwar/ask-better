Get started

Install, add a key, optimize.

Nothing to sign up for. Bring an API key from the provider you already use and the Optimize button is ready the next time you open a chat.

Add AskBetter to Chrome

Install it from the Chrome Web Store and pin it to the toolbar so the popup is one click away.

Pick a provider and verify your key

Open Settings, choose Google Gemini, OpenAI or Anthropic Claude, and press Verify key. The live model list loads straight from the provider.

Write, optimize, accept

Type a rough prompt in ChatGPT, Gemini or Claude, then press Optimize. Edit the preview if you like, then accept it into the prompt box.

Ctrl/⌘ + Shift + O works without reaching for the button.

Phrase Better works everywhere

Select text on any page, right-click and choose Re-phrase with AskBetter. Pick from one to three suggestions; nothing is replaced until you click one.

Choose how many options

Optimize can return up to three rewrites in a single request. Switch between them in the preview before accepting. The default is one, the cheapest.

Phrase Better

Rephrase anything you've selected.

Emails, tickets, comments, docs: select the text, right-click, and pick the phrasing you like. AskBetter remembers where the text came from, so it lands in the right place.

  • Four presets: fix grammar (the default), rephrase, casual reply and formal message.
  • Stack adjustments on top: keep my voice, polish wording, a little wit, or humanize.
  • Natural line breaks keep greetings, sign-offs and paragraphs where they belong.
  • Nothing is replaced until you click a suggestion. Esc dismisses it.

Privacy

Your prompts stay yours.

AskBetter has no backend. Everything runs in your browser, and your API key never touches a server we own.

No backend server

Requests go straight from your browser to the provider you chose. There is no server in between.

Local storage only

Settings, keys, usage reports and history live in chrome.storage.local on your device. Never synced to the cloud.

Key isolation

Only the background service worker reads your API key. Content scripts, and the pages you visit, never see it.

Zero telemetry

No analytics or crash reporting leaves your device. Reports are computed and stored on your machine; we never see them.
